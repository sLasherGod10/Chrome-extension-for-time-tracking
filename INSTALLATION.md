# TimeTrack Pro — Glassmorphism UI

## Install in Chrome
1. Extract this folder if it is still inside a ZIP archive.
2. Open `chrome://extensions` in Chrome.
3. Enable **Developer mode**.
4. Select **Load unpacked** and choose this folder (the one containing `manifest.json`).
5. Pin **Website Tracker** to the toolbar and open the extension.

## What's updated
- Redesigned extension popup with a glass panel, animated session timer, glowing accents, and a dashboard action.
- Redesigned analytics dashboard with a responsive sidebar, animated hero area, glass cards, chart panels, and a cleaner tracking-rules table.
